# SQL queries & joins

Study notes for the demo (replace or extend with real course material).

WHERE filters rows before grouping, while HAVING filters groups after aggregation.

A LEFT JOIN keeps every row of the left table and fills NULLs when the right side has no match.

COUNT(*) counts rows while COUNT(column) skips NULLs.

NULL = NULL evaluates to unknown, so only IS NULL finds NULL values.
